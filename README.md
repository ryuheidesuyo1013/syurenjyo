# 蹴練場（Syurenjyo）

images/syurenjyo-ss.png

サッカー選手・指導者・保護者に向けて、技術・戦術・トレーニング・進路などの情報を発信するWebサイトです。

**公開サイト**
https://蹴練場.jp/

---

## 概要

企画・デザイン・コーディング・公開・運用まで一人で担当し、継続的に記事や機能を追加・改善しています。

サッカーの練習メニューを検索すると、自分が興味を持ったテーマに関連する情報ばかりに触れやすく、知識の幅が狭くなってしまうことがあります。
そこで、「チーム練習」と「個人練習」をカテゴリごとに整理し、利用者が幅広い知識を得られる情報サイトとして制作しました。

## 制作で工夫した点

* 表示速度を意識し、画像形式やファイルサイズを最適化
* モバイル・タブレット・PCのレスポンシブ対応
* 保守性を考慮したCSS・JavaScriptの分割
* 利用者が目的の記事へたどり着きやすい導線設計
* xmlサイトマップなどのSEO対策

## 学んだこと

本プロジェクトを通して、Webサイトは公開して終わりではなく、利用者の視点で継続的に改善していくことが重要だと学びました。

デザインや機能だけでなく、表示速度やSEO、保守性なども含めて品質を高めることの大切さを実感しています。
